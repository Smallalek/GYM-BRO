# 🏋️ GYM-BRO

![Android](https://img.shields.io/badge/Platform-Android-green.svg)
![Status](https://img.shields.io/badge/Status-Active-blue.svg)

**GYM-BRO** is an Android application designed to help you track your daily activities, monitor how often you train, and organize the types of exercises you plan to use.

## ✨ Features

- **Activity Tracking:** Log your daily movements.
- **Workout Logger:** Keep track of how often you hit the gym.
- **User Friendly:** Simple interface designed for quick entry during workouts.

---

## 🚀 Installation

You can download the latest version of the app directly from this repository's **Releases** section.

1. Go to the [**Releases**](https://github.com/Smallalek/GYM-BRO/releases/tag/v1.0.0) page.
2. Download the latest `.apk` file to your Android phone.
3. Open the file to install it. *(Note: You may need to enable "Install from Unknown Sources" in your phone's settings).*
